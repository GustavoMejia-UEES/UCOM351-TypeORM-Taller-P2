# Taller 7 — Sesión 5: CRUD, validación y errores

Evidencia de `ValidationPipe`, DTOs de crear/actualizar/consultar, alta y reutilización de etiquetas, actualización parcial, eliminación HTTP 204 y traducción de errores PostgreSQL a respuestas HTTP.

Las respuestas y salidas guardadas corresponden a la ejecución local de esta rama. El reto CRUD de álbumes que las diapositivas dejan para la próxima clase queda fuera de este taller.

- `build-terminal.txt` y `seed-terminal.txt`: compilación y datos de prueba.
- `api-terminal.txt` / `api-terminal.png`: respuestas HTTP de los casos válidos y errores.
- `foto-creada.json` y `foto-actualizada.json`: respuestas completas de POST y PATCH.
- `postgres-terminal.txt` / `postgres-terminal.png`: estado final de las tablas y sus relaciones.
- `api.http` en la raíz del repo y `verify-api.ps1`: solicitudes guardadas y comprobación reproducible.
