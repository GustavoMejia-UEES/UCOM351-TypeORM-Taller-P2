# Taller 6 — Sesión 4: relaciones y consultas

Verificación de las relaciones, filtros, paginación, el álbum en cada foto y la ruta anidada.

La guía de esta sesión usa `Etiqueta.texto`; la entidad y el filtro por etiqueta siguen ese nombre de campo.

- `api-terminal.txt` / `api-terminal.png`: filtro por etiqueta, orden, álbum incluido y ruta anidada.
- `filtro-relaciones.json` y `album-con-fotos.json`: respuestas completas de la API.
- `postgres-terminal.txt` / `postgres-terminal.png`: conteos y relaciones reales de PostgreSQL, incluida la tabla `fotos_etiquetas`.
- `seed-terminal.txt`: salida de `npm run seed`.
- `verify-api.ps1`: solicitudes reproducibles.
